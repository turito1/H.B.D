# Turito's Little Ocean 🪼

A dreamy birthday website made for Turito.

## Add her photo
Put the image in the project root and name it exactly:

`turito.jpg`

The HTML already references this filename.

## Run locally
Open `index.html` in your browser.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `turito.jpg`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then save.
6. Wait for GitHub Pages to provide your website link.

Tip: If her image is PNG, either convert it to JPG or change `turito.jpg` in `index.html` to `turito.png`.
